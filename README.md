# O'zbek Made

O'zbek brendlarini bir joyda kashf qilish g'oyasini tushuntiruvchi soft UI landing page.

## Ishga tushirish

Bu MVP funksional marketplace emas, konsept taqdimoti sifatida tayyorlangan. Loyiha hech qanday build step talab qilmaydi:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Keyin `http://localhost:4173` manzilini oching.

## Tarkibi

- `index.html` — Uzbek tilidagi konsept landing page
- `styles.css` — soft UI dizayn, responsive layout va animatsiyalar
- `script.js` — mobil menyu, konsept toast va demo qadam hover holatlari
- `assets/` — O'zbek hunarmandchiligi uchun mahalliy vizual materiallar
